# Debug

Element dumps and XPath locators, ported from ``FlaUI.Core.Debug``. The same calls are available
on every element as [`AutomationElement.details`](automation_element.md) and
`AutomationElement.get_xpath_to_element`. See [Utilities → Debugging elements](../utilities.md#debugging-elements)
for a walkthrough.
